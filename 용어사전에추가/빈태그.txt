react tsx에서 <></>의 의미?                    React TSX에서 <></>는 
Fragment(프래그먼트)의 
단축 Syntax입니다. 
컴포넌트가 여러 개의 요소를 
반환해야 할 때, 
불필요한 DOM 노드(예: <div>)를 
추가하지 않고 
그룹화할 수 있게 해줍니다.

주요 특징
불필요한 태그 방지: <div>로 감싸면 
HTML 구조에 의미 없는 상자 생김. 
프래그먼트는 DOM에 반영되지 않음.
단축 문법: <React.Fragment> 대신 
짧고 편한 <></> 사용 가능.
주의사항: key 속성 전달 불가 
(key가 필요하면 
<React.Fragment key={id}> 사용).

react tsx에서 inline 스타일 쓰는 법?   
React TSX에서 인라인 스타일은
style 속성에 자바스크립트 객체({})를
전달하여 작성합니다.
CSS 속성 이름은 대소문자를 구분하는
카멜케이스(camelCase)를 사용해야 합니다.
알아두어야 할 핵심 작성법은 다음과 같습니다:
직접 작성하기 (이중 중괄호)JSX 내부에서 
바깥쪽 중괄호 {}(자바스크립트 영역 표시)와 
안쪽 중괄호 {}(객체 표현)를 함께 사용합니다.
<div style={{ color: 'red', fontSize: '16px' }}>텍스트</div> 형태로 적습니다.
픽셀(px) 단위 등의 값은
문자열('16px')로 넣으며,
숫자인 경우 일부 속성(예: zIndex, opacity)은 
숫자 값 그대로 쓸 수도 있습니다.
객체 변수로 분리하여 적용하기
TSX 컴포넌트 상단이나 외부에 스타일 객체를 미리 선언합니다.타입스크립트를 쓸 경우 React.CSSProperties 타입을 지정해 주면 자동 완성 및 타입 검사를 지원받아 편리합니다.const boxStyle: React.CSSProperties = { backgroundColor: 'blue', padding: '10px' };
<div style={boxStyle}>상자</div> 형식으로 속성에 넣어줍니다.

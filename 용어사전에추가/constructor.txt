react tsx에서 constructor의 의미
React TSX(TypeScript + React)에서 constructor(생성자)는 
클래스형 컴포넌트(class component)가 생성될 때 가장 먼저 
실행되는 초기화 메서드입니다. 
주로 this.state 초기화나 이벤트 메서드 바인딩에 사용됩니다. 
현대 리액트에서는 클래스 대신 함수형 컴포넌트와 훅(Hook)을 
주로 쓰기 때문에 잘 쓰이지 않지만, 
레거시 코드나 클래스형 구조에서 볼 수 있습니다.
주요 역할과 특징
컴포넌트 초기화: 컴포넌트가 화면에 마운트(렌더링)되기 전 실행됩니다.
super(props) 필수: 타입스크립트/자바스크립트 클래스에서 
부모 클래스(React.Component)의 기능을 상속받으려면 반드시 
super(props)를 먼저 호출해야 합니다. 
안 하면 this.props를 쓸 때 에러가 납니다.
this.state 정의: TSX 환경에서 상태의 타입을 지정하며 
this.state = { ... } 형태로 초기값을 넣습니다.
코드 예시 (TypeScript 클래스형 컴포넌트)tsx

import { Component } from 'react';

interface Props {
  name: string;
}

interface State {
  count: number;
}

class Counter extends Component<Props, State> {
  // constructor 정의
  constructor(props: Props) {
    super(props); // 부모 생성자 호출
    this.state = {
      count: 0, // state 초기화
    };
  }

  render() {
    return <div>{this.state.count}</div>;
  }
}

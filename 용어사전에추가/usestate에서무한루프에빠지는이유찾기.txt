usestate에서 무한루프에 빠지는 이유          
useState 자체는 상태를 저장하는 도구일 뿐이며, 
그 값을 조건 없이 렌더링 도중(컴포넌트 본문 안)에서 
직접 수정하거나, 
상태가 바뀔 때마다 실행되는 useEffect 안에서 
종속성 관리 실수로 상태를 계속 갱신할 때 
무한 루프(무한 렌더링)에 빠지게 됩니다.
주요 원인
렌더링 중 직접 상태 호출: 컴포넌트 함수 내부에서 setCount(count + 1)처럼 
조건문 없이 상태를 바로 바꾸면, 
렌더링 -> 상태 변경 -> 재렌더링 과정이 무한 반복됩니다.
useEffect 안에서 상태 변경 및 의존성 배열 누락: useEffect 안에서 setState를 쓰면서 
의존성 배열을 안 쓰거나, 상태 값 자체를 
의존성에 넣어 변화가 계속 감지되는 경우 발생합니다.
객체나 배열을 매번 새로 생성하여 전달: 매 렌더링마다 
새로운 참조 주소를 가진 객체를 만들어 useEffect나 
자식 컴포넌트에 넘기면 상태가 바뀐 것으로 오인하여 
루프가 생깁니다.해결 방법
조건문 사용하기: 상태를 변경하는 코드는 
반드시 이벤트 핸들러(onClick 등)나 
특정 조건(if) 안에서만 실행되도록 감쌉니다.
useEffect 의존성 배열 점검하기: 상태를 
업데이트하는 이유와 시점이 정확한지 확인하고,
 불필요한 상태 갱신 코드를 제거합니다.
함수형 업데이트 쓰기: 이전 상태 값을 
기반으로 바꿀 때는 setCount(prev => prev + 1) 형태를 사용합니다.




React에서 무한 루프 없이 useState를 안전하고 올바르게 사용하는 3가지 필수 패턴입니다.
------------------------------
## 1. 이벤트 핸들러 안에서 상태 변경하기
가장 흔한 실수인 '렌더링 중 직접 호출'을 방지하는 방법입니다. 상태 변경 함수를 버튼 클릭 같은 사용자 행동(이벤트)이 일어날 때만 실행되도록 분리합니다.

import { useState } from 'react';

function ClickCounter() {
  const [count, setCount] = useState(0);

  // 컴포넌트 본문이 아닌, 이벤트 핸들러 함수 내부에서 호출
  const handleIncrement = () => {
    setCount(count + 1); 
  };

  return (
    <div>
      <p>카운트: {count}</p>
      {/* 잘못된 예: onClick={setCount(count + 1)} -> 무한 루프 */}
      <button onClick={handleIncrement}>1 증가</button>
    </div>
  );
}

## 2. 함수형 업데이트 사용하기
이전 상태 값을 안전하게 참조하여 업데이트할 때 사용합니다. 특히 동일한 이벤트 안에서 상태를 여러 번 변경하거나 의존성을 줄이고 싶을 때 무한 루프를 완벽히 차단합니다.

import { useState } from 'react';

function SafetyCounter() {
  const [count, setCount] = useState(0);

  const handleAsyncIncrement = () => {
    // prev는 항상 가장 최신의 상태 값을 보장합니다.
    setCount(prev => prev + 1);
  };

  return (
    <button onClick={handleAsyncIncrement}>현재 값: {count}</button>
  );
}

## 3. useEffect 내에서 올바른 의존성 배열 사용하기
API 호출 등 데이터 페칭 후 상태를 저장할 때 무한 루프를 막는 핵심 구조입니다. 의존성 배열([])을 비워두면 컴포넌트가 처음 나타날 때(마운트) 딱 한 번만 실행됩니다.

import { useState, useEffect } from 'react';

function UserProfile() {
  const [userData, setUserData] = useState(null);

  useEffect(() => {
    // 이 내부에 setCount를 넣고 의존성 배열을 안 쓰면 무한 루프 발생!
    fetch('https://example.com')
      .then(res => res.json())
      .then(data => setUserData(data));
  }, []); // 빈 배열([])을 넣어 처음에 딱 한 번만 실행되도록 제한

  return (
    <div>{userData ? userData.name : '로딩 중...'}</div>
  );
}

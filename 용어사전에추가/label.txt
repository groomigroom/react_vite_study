
<label htmlFor="title">제목</label> 
<input type="text" name="title" placeholder="텍스트 입력" /> 
이런식으로 react tsx에서 작성하면 title로 연결이 되나?
네, htmlFor="title"과 id="title"을 함께 써야 연결됩니다.
현재 코드에는 id가 없어서 연결되지 않습니다.
수정 방법<label htmlFor="title">과 <input id="title" ... /> 형태로 id를 추가해야 합니다.
name="title"은 서버로 데이터를 보낼 때 쓰는 이름이므로, 
라벨과 클릭 시 커서 이동 연결과는 다릅니다.
올바른 코드 예시
<label htmlFor="title">제목</label><input type="text" id="title" name="title" placeholder="텍스트 입력" />

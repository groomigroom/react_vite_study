react에서 클래스 파일을 만들 때, 
tsx가 아닌 ts로 만드는 이유?                
React 프로젝트에서 클래스 파일이나 
유틸리티 파일 등을 tsx가 아닌 ts 
확장자로 만드는 이유는 해당 파일 
내부에 JSX(<div>, <Component /> 
등 HTML과 유사한 태그) 
문법이 전혀 포함되어 있지 않기 때문입니다.
.ts와 .tsx의 핵심 차이.ts (TypeScript): 순수한 타입스크립트 
코드만 작성하는 파일입니다. 
비즈니스 로직, API 호출 함수, 
공통 유틸리티, 일반 클래스, 
타입/인터페이스 정의 등에 사용됩니다.
.tsx (TypeScript XML): 타입스크립트에 
JSX 문법이 결합된 파일입니다. 
React UI 컴포넌트를 정의하고 화면을 
렌더링하는 코드가 포함될 때 사용합니다.
.ts를 사용하는 구체적 이유
JSX 부재: 파일 안에서 UI 마크업(HTML 태그)을 
반환하거나 생성하지 않고 순수 데이터 
처리나 객체 지향 클래스 로직만 다루므로 
.tsx를 쓸 이유가 없습니다.
명확한 의도 전달: 확장자만 보고도 이 파일은 
UI 컴포넌트가 아니라 순수 로직/데이터를 
다루는 모듈임을 다른 개발자와 컴파일러에게 
직관적으로 알릴 수 있습니다.

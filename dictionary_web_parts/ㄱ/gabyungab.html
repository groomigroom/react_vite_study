가변(mutable) 값 리액트(React)와 JSX에서 가변(mutable) 값은 생성된 이후 내부의 데이터나 상태를 직접 수정(mutation)할 수 있는 객체나 배열 같은 참조 타입 데이터를 의미합니다. 리액트에서는 상태(State)를 가변 값처럼 직접 수정하면 화면이 다시 그려지지 않거나 오류가 생기므로, 값을 바꿀 때 불변성(Immutability)을 지켜 새 껍데기로 교체해야 합니다. 가변 값의 핵심 특징 직접 수정 가능: 메모리에 있는 원래 데이터의 속성이나 요소를 직접 바꿀 수 있습니다. 참조 주소 유지: 데이터의 내용은 바뀌어도 변수가 가리키는 메모리 주소는 그대로 유지됩니다. 리액트 상태 제약: useState로 만든 상태를 직접 고치면 리액트가 변경을 알아차리지 못합니다. 리액트에서의 주의점 직접 변경 금지: state.push()나 state.value = 1처럼 직접 값을 바꾸는 가변 방식은 피해야 합니다. 세터 함수 사용: 대신 setState를 통해 새로운 객체나 배열을 전달하여 값을 갱신해야 안전합니다. 예외(Ref): useRef는 값이 변해도 화면을 다시 그리지 않는 가변 값을 관리할 때 예외적으로 사용합니다.

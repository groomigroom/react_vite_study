current는 리액트에서 주로 useRef 훅(Hook)을 사용할 때 생성되는 객체의 유일한 속성(Property) 이름입니다. [1, 2] 
리액트에서 const myRef = useRef(initialValue); 형태로 레퍼런스를 생성하면, 리액트는 { current: initialValue } 형태의 단순한 자바스크립트 객체를 만들어 줍니다. 이 객체 안의 실제 데이터나 값에 접근하고 변경할 때 항상 .current 문법을 사용하게 됩니다.
.tsx 환경에서도 역할은 같지만, 참조하는 대상(DOM 요소인지, 일반 변수인지)에 따라 타입스크립트가 타입을 엄격하게 추론해 준다는 점이 특징입니다.
------------------------------
## 💡 왜 .current라는 속성을 거쳐서 쓸까요?
리액트 컴포넌트는 내부 상태(useState)가 바뀌면 화면을 다시 그립니다(리렌더링). 하지만 useRef의 .current 값을 변경할 때는 컴포넌트가 리렌더링되지 않습니다. [3, 4] 
컴포넌트가 아무리 자주 리렌더링되어도, useRef가 반환한 객체의 주소값은 보존되며 오직 .current 안의 값만 유지되거나 변경됩니다. 즉, "화면은 바꾸지 않으면서 값만 안전하게 저장하고 싶을 때" 사용합니다. [5] 
------------------------------
## ⚙️ 언제 사용하나요? (2가지 핵심 용도)## 1. HTML DOM 요소에 직접 접근할 때 (가장 흔한 케이스)
포커스를 주거나, 스크롤 위치를 조작하는 등 HTML 태그를 직접 건드려야 할 때 사용합니다.

* .tsx 환경에서는 렌더링 직후(초기화 전)에는 값이 존재하지 않을 수 있으므로, .current가 존재하는지 검사(Optional Chaining 등)하는 과정이 필요합니다.

import { useRef } from "react";
export function TextInputWithFocusButton() {
  // 1. input 엘리먼트를 가리킬 ref 생성 (TSX에서는 타입 지정이 필요합니다)
  const inputRef = useRef<HTMLInputElement>(null);

  const onButtonClick = () => {
    // 2. inputRef.current가 비어있지 않다면(존재한다면) 포커스를 줍니다.
    inputRef.current?.focus(); 
  };

  return (
    <>
      <input ref={inputRef} type="text" />
      <button onClick={onButtonClick}>인풋창에 포커스 주기</button>
    </>
  );
}

## 2. 리렌더링을 유발하지 않는 '변수'로 쓸 때
타이머 ID, 이전 상태 값, 컴포넌트가 마운트되었는지 여부 등 UI와는 직접 상관없지만 기억해야 하는 값을 다룰 때 씁니다.

import { useRef, useEffect } from "react";
export function TimerComponent() {
  // 타이머 ID를 기억할 ref (초기값은 null)
  const timerIdRef = useRef<number | null>(null);

  useEffect(() => {
    // .current에 타이머 ID 저장
    timerIdRef.current = window.setInterval(() => {
      console.log("1초마다 실행");
    }, 1000);

    return () => {
      // 컴포넌트가 사라질 때 .current에 담긴 ID로 타이머 해제
      if (timerIdRef.current) {
        clearInterval(timerIdRef.current);
      }
    };
  }, []);

  return <div>타이머가 작동 중입니다.</div>;
}

------------------------------
## 🟦 TSX(타입스크립트) 환경에서 .current 주의점
타입스크립트에서 useRef에 초기값으로 null을 넣고 DOM 요소를 연결하면, .current 속성은 '읽기 전용(Read-only)'이 됩니다. 리액트가 컴포넌트 렌더링 시 DOM 엘리먼트를 알아서 대입해주기 때문입니다.

const myRef = useRef<HTMLInputElement>(null);
// ❌ 에러 발생: TSX에서 DOM 레퍼런스의 .current는 직접 수정할 수 없습니다.
myRef.current = someOtherElement; 
// ⭕ 올바른 예시: 내부의 속성이나 메서드를 호출하는 것은 가능합니다.
myRef.current.value = "hello"; 

반면, 일반 변수 값을 담을 목적으로 useRef(0) 처럼 초기 숫자를 주면 .current 값을 자유롭게 읽고 쓸 수 있게 추론됩니다.

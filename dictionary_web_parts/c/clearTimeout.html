react tsx에서 clearTimeout
React TSX(타입스크립트)에서 clearTimeout은 setTimeout으로 예약한 타이머(실행 대기 작업)를 취소(중지)하는 MDN Web Docs 전역 함수입니다.
핵심 역할은 타이머 취소, 메모리 누수 방지, 그리고 컴포넌트 생명주기 관리입니다.
주요 의미와 역할
타이머 취소: setTimeout이 지정된 시간이 되기 전에 실행을 막아줍니다.
메모리 누수 방지: 컴포넌트가 화면에서 사라진(unmount) 뒤에도 타이머가 남아 메모리를 차지하는 문제를 막아줍니다.
불필요한 상태 변경 방지: 사라진 컴포넌트의 상태를 바꾸려다 발생하는 에러를 예방합니다.
사용 방법과 예시타이머 ID 저장: setTimeout을 실행하면 나오는 숫자(ID)를 변수에 담습니다.
clearTimeout(변수명) 호출: 필요할 때 이 함수에 변수명을 넣어 타이머를 끕니다.
useEffect 정리(cleanup): 리액트에서 컴포넌트가 사라질 때 return () => { clearTimeout(id); } 형태로 주로 사용합니다.

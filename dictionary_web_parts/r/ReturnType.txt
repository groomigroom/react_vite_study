ReturnType은 리액트나 TSX 전용 문법이 아니라, 타입스크립트(TypeScript)가 자체적으로 제공하는 내장 유틸리티 타입입니다. [1]
의미는 말 그대로 "특정 함수의 반환 타입(Return Type)이 무엇인지 추출해내는 도구"입니다. [1] 리액트 컴포넌트나 커스텀 훅(Custom Hook)도 결국 '함수'이기 때문에, 이들이 반환하는 결과물의 타입을 안전하게 가져오고 싶을 때 유용하게 사용됩니다. [1]
------------------------------
## 💡 왜 사용하나요? (핵심 이유)
코드를 작성하다 보면 "내가 만든 어떤 함수의 결과물(객체나 값)의 타입을 그대로 가져와서 다른 곳에 선언하고 싶다"는 생각이 들 때가 있습니다.
직접 타입을 일일이 손으로 타이핑(interface나 type 선언)할 수도 있지만, 함수 내부 코드가 수정되어 반환값이 바뀌면 타입 선언도 매번 수정해야 하는 번거로움이 생깁니다. ReturnType을 쓰면 함수의 실제 반환값을 기반으로 타입이 자동 동기화되므로 코드 관리가 훨씬 편해집니다. [1]
------------------------------
## ⚙️ 어떻게 사용하나요? (기본 문법)
ReturnType 뒤에 꺾쇠괄호 <>를 붙이고, 그 안에 typeof 함수이름을 넣어서 사용합니다. [1] [1] 

// 1. 일반적인 함수 선언function getUser() {
  return { id: 1, name: "Kim", age: 20 };
}
// 2. ReturnType을 이용해 함수의 반환 타입을 자동으로 추출type UserInfo = ReturnType<typeof getUser>; 
/*
  추출된 UserInfo 타입은 사실상 아래와 동일하게 작동합니다:
  type UserInfo = {
    id: number;
    name: string;
    age: number;
  };
*/
// 3. 추출한 타입을 다른 변수나 함수에서 안전하게 재사용const myProfile: UserInfo = {
  id: 2,
  name: "Lee",
  age: 25
};

------------------------------
## ⚛️ 리액트 .tsx 환경에서의 실제 활용 예시
리액트 개발을 할 때는 주로 커스텀 훅(Custom Hook)의 반환 타입을 컴포넌트에서 재사용할 때 가장 많이 쓰입니다.
## 예시: Custom Hook과 컴포넌트 간의 타입 연동
만약 아래와 같이 복잡한 객체나 상태들을 반환하는 커스텀 훅이 있다고 가정해 보겠습니다.

// hooks/useCounter.tsimport { useState } from "react";
export function useCounter() {
  const [count, setCount] = useState<number>(0);
  const increment = () => setCount((prev) => prev + 1);
  const decrement = () => setCount((prev) => prev - 1);

  // 이 훅은 다양한 함수와 상태를 묶어서 반환합니다.
  return { count, increment, decrement };
}
// 훅이 반환하는 모든 것들의 타입을 '자동으로' 추출합니다.export type UseCounterResult = ReturnType<typeof useCounter>;

이제 위에서 추출한 UseCounterResult 타입을 다른 자식 컴포넌트의 props 타입 등으로 요긴하게 재사용할 수 있습니다.

// components/CounterDisplay.tsximport { UseCounterResult } from "../hooks/useCounter";
// 부모에게서 훅의 결과물을 통째로 전달받을 때 타입을 안전하게 지정 가능!interface Props {
  counterTools: UseCounterResult; 
}
export function CounterDisplay({ counterTools }: Props) {
  return (
    <div>
      <p>현재 카운트: {counterTools.count}</p>
      <button onClick={counterTools.increment}>증가</button>
    </div>
  );
}

이렇게 하면 나중에 useCounter 훅에서 반환하는 값에 새로운 기능(예: reset 함수 등)이 추가되더라도, ReturnType 덕분에 CounterDisplay 컴포넌트의 타입도 자동으로 업데이트됩니다.
------------------------------
현재 작성 중이신 코드에서 ReturnType을 적용해보고 싶은 특정 함수나 커스텀 훅이 있으신가요? 코드를 보여주시면 어떻게 타입을 추출하고 연결해야 하는지 직접 정형화해 드릴 수 있습니다.

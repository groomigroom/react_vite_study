state.push()에서 state는 리액트가 관리하는 상태(컴포넌트의 데이터)이자 현재 시점의 '배열(Array)' 객체를 의미합니다. ## 1. 기술적 의미 * useState로 선언된 배열 변수 자체를 가리킵니다. * JavaScript의 일반 배열과 똑같은 메모리 주소를 가진 참조 타입 데이터입니다. [1, 2] ## 2. 예시 코드로 보기 const [state, setState] = useState(['사과', '바나나']); * 위 코드에서 state는 ['사과', '바나나']라는 값을 가진 배열입니다. * 따라서 state.push('포도')라고 쓰는 것은 리액트 상태 변수인 배열 뒤에 '포도'를 직접 밀어 넣겠다는 뜻입니다. ## 3. 구조적 문제점 * state는 리액트가 눈을 크게 뜨고 감시하고 있는 데이터입니다. * 하지만 push()를 쓰면 리액트 몰래 내부 값만 바꾸는 꼴이 되기 때문에, 리액트는 state가 변했다는 사실을 눈치채지 못합니다. 현재 작성 중인 useState 선언부나 어떤 데이터 타입을 배열에 넣으려고 하시는지 알려주시면 가장 안전한 상태 업데이트 로직을 제안해 드릴 수 있습니다.

forwardRref React TSX에서 forwardRef는 부모 컴포넌트의 ref를 자식 커스텀 컴포넌트로 전달해 내부 DOM에 접근하게 돕는 기능이며, React와 TypeScript로 ForwardRef Input 컴포넌트 생성 가이드와 같이 타입 정의를 결합해 안정성을 높입니다. 주요 개념 및 의미 참조 전달: 부모가 만든 ref 객체를 자식 컴포넌트의 특정 HTML 요소(input, div 등)에 연결할 수 있습니다. 타입 안전성: TSX 환경에서는 React.forwardRef 형태를 사용해 전달받을 ref와 props의 타입을 정확히 지정해야 합니다. 직접 제어: 포커스 이동, 스크롤 위치 제어, 값 읽기 등 DOM을 직접 조작해야 하는 상황에 필수적입니다. 사용 이유와 특징리액트의 일반 함수 컴포넌트는 기본적으로 ref라는 이름을 prop으로 받을 수 없어 에러가 발생합니다. forwardRef는 컴포넌트를 감싸서 두 번째 매개변수로 ref를 받을 수 있게 열어줍니다.

const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => { ... };사용자가 입력창에 글자를 타이핑하는 등 값이 변경될 때 실행될 함수(handleChange)를 정의합니다.e는 이벤트(Event) 객체로, 사용자가 입력창에서 어떤 행동을 했는지에 대한 정보를 담고 있습니다.TypeScript 문법 (: React.ChangeEvent<HTMLInputElement>):이 함수가 'HTML <input> 태그의 값이 변하는 이벤트'만 처리하도록 타입을 엄격하게 제한합니다.오타를 방지하고 자동 완성 기능을 쓸 수 있게 도와줍니다.setSelectedValue(e.target.value);e.target은 이벤트가 발생한 대상, 즉 사용자가 글자를 입력하고 있는 <input> 태그 자체를 의미합니다.e.target.value는 사용자가 현재 입력창에 타이핑한 텍스트 값입니다.setSelectedValue(...)는 상태 변경 함수(State Updater)입니다. 입력된 새 값을 React의 상태(selectedValue)로 저장하여 화면을 새로고침(리렌더링)하도록 만듭니다.


네, 정확합니다! onChange나 onClick 같은 이벤트 리스너에 연결된 함수는 첫 번째 매개변수로 이벤트 객체를 자동으로 전달받도록 설계되어 있습니다.
이것은 React나 TypeScript만의 특별한 문법이 아니라, 브라우저(JavaScript)가 작동하는 기본적인 규칙입니다.
------------------------------
## ⚙️ 브라우저와 React의 작동 원리
우리가 화면에서 무언가를 조작할 때, 브라우저는 뒤에서 다음과 같이 행동합니다.

   1. 사건 발생: 사용자가 입력창에 키보드를 누릅니다.
   2. 보고서 작성: 브라우저가 "몇 시 몇 분에, 어떤 input 태그에서, 어떤 글자가 입력되었다"라는 상세 보고서(이벤트 객체)를 내부적으로 만듭니다.
   3. 함수 호출: 우리가 연결해 둔 handleChange 함수를 실행하면서, 첫 번째 배달물(매개변수)로 그 보고서를 휙 던져줍니다.

따라서 우리는 매개변수 자리에 빈 칸을 만들어 두기만 하면, 브라우저가 알아서 그 자리에 이벤트 보고서를 채워 넣어 줍니다.
------------------------------
## 💡 코드로 보는 비교## 1. 보고서를 받아서 쓰는 경우 (일반적)
첫 번째 자리에 변수(e)를 적어두면 브라우저가 준 보고서를 열어볼 수 있습니다.

const handleChange = (e) => {
  // e 자리에 브라우저가 준 보고서가 들어옵니다.
  console.log(e.target.value); 
};

## 2. 보고서가 필요 없는 경우
만약 사용자가 클릭했다는 사실만 중요하고, 상세 보고서(어디를 클릭했는지 등)가 필요 없다면 매개변수를 아예 비워두고 이름만 지어줘도 됩니다.

const handleClick = () => {
  // 매개변수를 안 적어도 함수는 실행됩니다.
  alert("버튼이 클릭되었습니다!"); 
};

------------------------------
요약하자면, "이벤트가 발생해서 실행되는 함수는 무조건 첫 번째 매개변수로 이벤트 보고서(event)를 받는다"가 웹 브라우저의 기본 약속입니다.
혹시 이 이벤트 객체(e) 안에는 target.value 외에 또 어떤 정보들이 들어있는지 궁금하신가요? 아니면 매개변수를 여러 개 전달하고 싶을 때 어떻게 해야 하는지 알고 싶으신가요?

React TSX에서 원하는 이름으로 타입을 만드는 방법은 type 키워드나 interface 키워드를 사용하는 것입니다.타입 정의 방법type 키워드: type 이름 = { 속성: 타입 } 형식으로 정의하며 = 기호가 들어갑니다.interface 키워드: interface 이름 { 속성: 타입 } 형식으로 정의하며 = 기호가 없습니다.코드 예시tsx// 1. type 키워드 사용
type UserType = {
  name: string;
  age: number;
};

// 2. interface 키워드 사용
interface UserInterface {
  name: string;
  age: number;
}

// 컴포넌트에서 사용하기
function UserProfile({ name, age }: UserType) {
  return (
    <div>
      <p>이름: {name}</p>
      <p>나이: {age}</p>
    </div>
  );
}

const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => { ... };사용자가 입력창에 글자를 타이핑하는 등 값이 변경될 때 실행될 함수(handleChange)를 정의합니다.e는 이벤트(Event) 객체로, 사용자가 입력창에서 어떤 행동을 했는지에 대한 정보를 담고 있습니다.TypeScript 문법 (: React.ChangeEvent<HTMLInputElement>):이 함수가 'HTML <input> 태그의 값이 변하는 이벤트'만 처리하도록 타입을 엄격하게 제한합니다.오타를 방지하고 자동 완성 기능을 쓸 수 있게 도와줍니다.setSelectedValue(e.target.value);e.target은 이벤트가 발생한 대상, 즉 사용자가 글자를 입력하고 있는 <input> 태그 자체를 의미합니다.e.target.value는 사용자가 현재 입력창에 타이핑한 텍스트 값입니다.setSelectedValue(...)는 상태 변경 함수(State Updater)입니다. 입력된 새 값을 React의 상태(selectedValue)로 저장하여 화면을 새로고침(리렌더링)하도록 만듭니다.


네, 정확합니다! onChange나 onClick 같은 이벤트 리스너에 연결된 함수는 첫 번째 매개변수로 이벤트 객체를 자동으로 전달받도록 설계되어 있습니다.
이것은 React나 TypeScript만의 특별한 문법이 아니라, 브라우저(JavaScript)가 작동하는 기본적인 규칙입니다.
------------------------------
## ⚙️ 브라우저와 React의 작동 원리
우리가 화면에서 무언가를 조작할 때, 브라우저는 뒤에서 다음과 같이 행동합니다.

   1. 사건 발생: 사용자가 입력창에 키보드를 누릅니다.
   2. 보고서 작성: 브라우저가 "몇 시 몇 분에, 어떤 input 태그에서, 어떤 글자가 입력되었다"라는 상세 보고서(이벤트 객체)를 내부적으로 만듭니다.
   3. 함수 호출: 우리가 연결해 둔 handleChange 함수를 실행하면서, 첫 번째 배달물(매개변수)로 그 보고서를 휙 던져줍니다.

따라서 우리는 매개변수 자리에 빈 칸을 만들어 두기만 하면, 브라우저가 알아서 그 자리에 이벤트 보고서를 채워 넣어 줍니다.
------------------------------
## 💡 코드로 보는 비교## 1. 보고서를 받아서 쓰는 경우 (일반적)
첫 번째 자리에 변수(e)를 적어두면 브라우저가 준 보고서를 열어볼 수 있습니다.

const handleChange = (e) => {
  // e 자리에 브라우저가 준 보고서가 들어옵니다.
  console.log(e.target.value); 
};

## 2. 보고서가 필요 없는 경우
만약 사용자가 클릭했다는 사실만 중요하고, 상세 보고서(어디를 클릭했는지 등)가 필요 없다면 매개변수를 아예 비워두고 이름만 지어줘도 됩니다.

const handleClick = () => {
  // 매개변수를 안 적어도 함수는 실행됩니다.
  alert("버튼이 클릭되었습니다!"); 
};

------------------------------
요약하자면, "이벤트가 발생해서 실행되는 함수는 무조건 첫 번째 매개변수로 이벤트 보고서(event)를 받는다"가 웹 브라우저의 기본 약속입니다.
혹시 이 이벤트 객체(e) 안에는 target.value 외에 또 어떤 정보들이 들어있는지 궁금하신가요? 아니면 매개변수를 여러 개 전달하고 싶을 때 어떻게 해야 하는지 알고 싶으신가요?

질문하신 (e: React.ChangeEvent<HTMLInputElement>) 문법은 JavaScript에 TypeScript의 타입 시스템이 결합된 원리입니다.
이 구조는 크게 2가지 파트로 나뉩니다. 왼쪽(e)은 데이터를 담는 주머니이고, 오른쪽(: 내용)은 그 주머니에 들어올 데이터의 검사표(타입)입니다.
그 작동 원리와 구조를 알기 쉽게 설명해 드릴게요.
------------------------------
## 1. 기본 원리: 변수 이름 + 타입 가이드라인
TypeScript에서는 변수나 매개변수를 만들 때, 콜론(:)을 붙여서 "이 변수에는 오직 이 종류의 데이터만 들어올 수 있어"라고 미리 규칙을 정해둡니다.

// 원리 예시const age: number = 25; // age에는 숫자(number)만 들어올 수 있음

따라서 (e: React.ChangeEvent<HTMLInputElement>)의 진짜 의미는 다음과 같습니다.

"첫 번째 매개변수로 이벤트 객체를 받아서 e라고 부를 건데, 이 e는 반드시 'React의 HTML Input 변경 이벤트 문서' 규격을 완벽하게 따른 데이터여야만 해!"

------------------------------
## 2. ': 내용' 부분을 더 깊게 뜯어보기
오른쪽에 적힌 복잡한 코드는 사실 React가 미리 만들어 둔 규격서 세트입니다.

   1. React.
   * React 라이브러리 안에서 정의된 규격을 사용하겠다는 뜻입니다.
   2. ChangeEvent
   * 값이 변경되는 사건(주로 input, select, textarea 등)에 대한 규격서입니다.
      * 이 안에는 target, currentTarget, timeStamp 같은 이벤트 공통 정보들이 정의되어 있습니다. [1] 
   3. <HTMLInputElement> (제네릭, Generic)
   * 화살표 괄호(< >)는 "더 구체적인 힌트를 줄게"라는 의미입니다.
      * 그냥 ChangeEvent라고만 하면 어떤 태그가 바뀌었는지 알 수 없기 때문에, <HTMLInputElement>를 붙여서 "이 이벤트는 다른 게 아니라 정확히 HTML의 <input> 태그에서 발생한 거야"라고 콕 집어 알려주는 것입니다.
      * 덕분에 개발 툴은 e.target 뒤에 점(.)을 찍었을 때, 일반적인 태그가 아니라 input 태그가 가진 속성(예: value, checked, type 등)을 자동 완성으로 똑똑하게 추천해 줄 수 있습니다. [2, 3, 4] 
   
------------------------------
## 3. 컴파일러(TypeScript)가 뒤에서 하는 일
이 코드가 작성되면 TypeScript 엔진은 실행되기 전에 코드를 검사합니다.

* 만약 개발자가 실수로 <input>이 아니라 버튼(<button>)에 이 handleChange 함수를 연결하려고 하면, "여기 적힌 규격은 Input 전용인데 왜 Button에 쓰려고 해?"라며 빨간 줄(에러)을 띄워 실수를 미리 잡아냅니다.
* 검사가 끝나고 실제 브라우저에서 실행될 때는, 이 : 내용 부분이 전부 흔적도 없이 사라지고 순수한 JavaScript 파일((e) => { ... })로 변환되어 실행됩니다. (브라우저는 타입을 이해하지 못하기 때문입니다.)

------------------------------
요약하자면, (e: 내용)은 "브라우저가 던져주는 이벤트 객체(e)를 안전하게 다루기 위해 React가 정한 엄격한 규격서(내용)를 바코드처럼 찍어둔 것"이 원리입니다.
혹시 이 문법 외에 함수에 내가 원하는 개인적인 값(예: 인덱스 번호나 ID값)을 매개변수로 함께 넘겨주고 싶을 때는 코드를 어떻게 짜야 하는지 궁금하신가요?
